🕸 Radar — multi-dimensional QA profile

QA Profile page
Each axis is one of the QA's six core skills. The shape immediately shows strengths and weaknesses. A faint second polygon (purple) overlays the team average — you instantly see where this QA outperforms and where they need to catch up.
→ Renders on every QA profile, above the Performance Trend chart.

What it showsStrengths and weaknesses in one image. The "coaching" dip is invisible in the existing per-cell tables — here it pops out. Comparison overlay is intuitive ("am I above or below my team on this axis").
Watch-outsWorks best for 5–8 axes (more = unreadable). Needs all six metrics to be normalised to 0–100 — fine for percentages, but RTR/Coaching counts need scaling.

🫧 Bubble scatter — team-at-a-glance

Dashboard (lead+ view)
X-axis: CSAT %. Y-axis: Performance %. Bubble size: survey count (confidence weight). Bubble colour: team lead. Every QA on the team appears as one bubble. Outliers — bottom-left (struggling), top-right (stars), top-left (high perf but low CSAT) — pop immediately. Click any bubble → QA profile.
→ Lives on the Dashboard, replaces or sits next to the current Performance Trend chart for leads with >5 reports.

🟩 Activity heatmap — year-in-a-grid

QA Profile page
GitHub-style 53-week × 7-day grid. Each cell is one day; colour intensity reflects something configurable (default: occupancy %). Vacation weeks, coaching cadence drops, long quiet stretches — patterns leap out from a year of data in one glance.
→ Renders on every QA profile, near the top. Drop-down to switch metric: Occupancy / Performance / Coaching count / Tickets.
Pola Emad — last 12 months · Occupancy % hover any cell for the day · click any month label to zoom

What it showsA full year of working life. Easy to spot patterns invisible elsewhere — leave clusters, consistent weeks vs lumpy weeks, return-from-vacation slumps, gradual ramps.
Watch-outsWide on small screens — needs horizontal scroll on mobile (or condense to last 90 days). 365 cells = 365 DOM nodes; perf fine but should virtualise if we ever do team-wide heatmap.
